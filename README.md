## Descrição do Projeto
Esse Projeto é um Landing Page do filme da Barbie, que foi desevlvido usando HTML, CSS e JavaScript. O projeto apresenta informações interessantes sobre o longa,
Como data de lançamento, sinopse, orçamento, faturamento, elenco e resenha de cinéfilos que viram o filme.

O Objetivo é desmontrar um HTML bem estruturado, um CSS responsívo e funções de JavaScrip que deixa a experiência de navegação mais interessante.

## Funcionalidades da Landing Page 
- Responsividade completa com outros disposítivos(Desktop, Mobile e Tablets).
- Botões interativos(ver mais e ver menos) para expandir informações.
- Estrutura semântica do HTML5(`<header>`, `<section>`,`<footer>','<article>'
- Layout de CSS organizado por classes.
- Alteração dinâmica de estilo e conteúdo com JavaScript
